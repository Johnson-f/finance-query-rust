## Historical Data

### `historical`

Retrieve historical stock price data with optional technical indicators.

**Arguments:**

| Argument     | Type           | Required | Description                                    | Example        |
|--------------|----------------|:--------:|------------------------------------------------|----------------|
| `symbol`     | `String!`      |    ✓     | Stock ticker symbol                            | `"TSLA"`       |
| `range`      | `String!`      |    ✓     | Historical time range                          | `"1y"`         |
| `interval`   | `String!`      |    ✓     | Data point frequency                           | `"1d"`         |
| `indicators` | `[String!]`    |          | Array of indicator types (`"sma"`, `"ema"`)    | `["sma", "ema"]` |
| `period`     | `String`       |          | Comma-separated periods (default: `"20"`)      | `"10,20,50"`   |

**Available Range Options:**
`1d`, `5d`, `1mo`, `3mo`, `6mo`, `ytd`, `1y`, `2y`, `5y`, `10y`, `max`

**Available Interval Options:**
`1m`, `3m`, `5m`, `10m`, `15m`, `20m`, `30m`, `65m`, `95m`, `1h`, `1d`, `1wk`, `1mo`

**Indicator Options:**
- `sma` - Simple Moving Average
- `ema` - Exponential Moving Average

**Example Query (Basic):**
```graphql
query {
  historical(symbol: "TSLA", range: "1y", interval: "1mo") {
    data
  }
}
```
