## Financials

### `financials`

Retrieve financial statements for a stock.

**Arguments:**

| Argument    | Type      | Required | Description                                                          | Example      |
|-------------|-----------|:--------:|----------------------------------------------------------------------|--------------|
| `symbol`    | `String!` |    ✓     | Stock ticker symbol                                                  | `"AAPL"`     |
| `statement` | `String`  |          | Statement type (`"income"`, `"balance"`, `"cashflow"`, default: `"income"`) | `"balance"` |
| `frequency` | `String`  |          | Frequency (`"annual"`, `"quarterly"`, default: `"annual"`)          | `"quarterly"` |

**Example Query:**
```graphql
qquery {
  financials(symbol: "AAPL", statement: "income", frequency: "annual") {
    symbol
    statementType
    frequency
    statement
  }
}
```
